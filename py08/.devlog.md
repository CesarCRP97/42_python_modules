### To create and activate VENV

1. python3 -m venv new_venv
2. source new_venv/bin/activate
3. To delete it, we only need to delete the directory created by python -m venv


### How we detect we are in the venv or not

'''python

def main() -> None:
    if sys.prefix == sys.base_prefix:
        show_normal_info()
    else:
        show_venv_info()

'''

### Why do we need virtual environments

- Better dependency management
- Avoid System pollution
- Dodge Installation Privilege Lockouts
